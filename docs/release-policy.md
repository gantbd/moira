# Release and distribution policy

Status: coordinated multi-repository source development only; no registry or
binary publication is authorized.

Every Moira package sets `publish = false`. The current checkout requires sibling
Keystone, Aegis, Agora, Chronos, Daimon and Hermes sources at documented relative
paths. Those direct peer dependencies are qualification inputs, not a stable
production connector or self-contained distribution contract.

The selected source profile now contains a private daemon and OS-account
authentication adapter, but no supported executable package, supervisor, remote
identity, peer services, real provider or operator application. Passing the local four-store
journey is not a distributed-transaction, remote deployment or physical
power-loss claim.

Enabling a distribution channel requires public peer-client boundaries,
immutable dependency provenance, license and compatibility review, SBOM/advisory
evidence, installation/upgrade/migration/removal qualification, updated security
and readiness records, and a deliberate change to fail-closed publication gates.
