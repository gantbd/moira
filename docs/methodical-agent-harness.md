## Objective

Extend the local model path into a governed agent system that supports chat,
workflow participation and authorized tool use while preserving the workspace's
sovereign-engine boundaries. The system must distinguish facts that can be
proved, choices that require accountable authority, unresolved evidence and
honest non-convergence.

## Ownership

- Rune owns authored methods, FSMs, SME groundings and fold rules.
- Dendrite serves exact Rune identities, ambient/activated/reference surfaces,
  fold results, concern orthogonality and corpus reconciliation.
- Moira owns durable deliberation and workflow coordination.
- Daimon executes one already-authorized bounded model or tool invocation and
  returns evidence and proposals.
- Chronos owns schedules, attempts and leases.
- Aegis owns authorization decisions.
- Agora owns conversation and publication semantics.
- Vellum owns document and edit semantics.

Neither a persona prompt nor model agreement is authority. Dendrite routing is
not semantic proof, and a Daimon proposal is not a peer-effect receipt.

## Capability profiles

The same engine core supports three progressively stronger profiles without
collapsing their authority:

- **chatbot:** Agora ingress and reply publication around one bounded Daimon
  completion; conversation identity and publication stay in Agora;
- **workflow:** a Rune-authored machine selects the current method and context
  tags, Dendrite supplies exact grounding, Moira retains transitions and
  Chronos owns scheduled attempts;
- **agent:** the workflow profile plus separately authorized Daimon tool
  continuations, each represented as its own Moira effect with an Aegis
  decision, budget and attributable receipt.

The strict operator makes those profiles executable invariants. A chatbot has
exactly one grounded member and uses a nonzero deployment-policy digest to
select that sole answer for peer action. A workflow has at least two grounded,
orthogonal members. An agent has the workflow shape and at least one advertised
tool. Workflow and agent peer actions require both `AuthorizedChoice` and a
separate exact Aegis action decision; tool calls retain their independent Aegis
and Chronos gates. None of these permission paths converts model agreement into
proof.

Dendrite is useful to workflows, but it is not their runtime. It answers which
authored method/state, fold, SME surface and concern lattice a transition is
grounded in. Moira owns durable workflow state and recovery; Chronos owns time;
Daimon owns bounded execution; Aegis owns permission. This lets hot-reloaded
expertise inform a workflow without allowing a corpus server to silently move
the workflow or authorize an effect.

## Epistemic result contract

The terminal contract must retain these distinct outcomes:

- `ProvenBool`: a decidable predicate was checked by an identified validator and
  carries an evidence witness.
- `AuthorizedChoice`: an accountable authority selected one member of the
  retained Pareto frontier under explicit criteria.
- `Maybe`: evidence currently supports true only, false only, both or neither.
- `Mu`: bounded deliberation stopped honestly, with a reason and reopen
  conditions rather than fabricated certainty.

Pareto analysis removes dominated candidates. It does not prove a surviving
candidate true and does not choose among incomparable survivors.

## Governed loop

1. Frame the question, authority, risk, budget and stopping condition.
2. Classify material claims as formal, empirical, normative, historical or creative.
3. Select the Rune activity machine and derive context tags.
4. Resolve ambient expertise through Dendrite; activate deeper surfaces only at
   the decision point that needs them.
5. Select the smallest useful ensemble by concern coverage and independence.
6. Run independently scoped Daimon invocations for the selected lenses.
7. Preserve reports and dissent before synthesis.
8. Challenge evidence, transfer assumptions, correlated agreement and missing alternatives.
9. Reconcile misunderstandings, real tradeoffs and unresolved contradictions.
10. Compute the Pareto frontier, then run deterministic validators where the
    predicate is decidable.
11. Resolve to proof, authorized choice, maybe or mu.
12. Ask Aegis before effects; let Moira coordinate attributed peer proposals and receipts.
13. Retain the machine, grounding, model, tool, evidence, dissent, authority and
    effect identities needed for replay and audit.

For an ensemble, step 12 applies only to a separately selected action result.
Retaining every expert report is epistemic evidence, not permission to execute
every report's peer proposals. A chatbot profile may make this gate trivial by
policy for its single answering member; a workflow or agent must bind selection
to its explicit resolution/authority path before Agora publication or Vellum
mutation.

Every revision loop has explicit fuel. Exhaustion produces `Mu`, never an
implicit retry or a confident model-authored boolean.

Admission requires Dendrite's retained orthogonality verdict to be affirmative.
A correlated ensemble is a typed refusal, not a weak consensus that later folds
as if its votes were independent; callers may reframe the ensemble or resolve a
separate bounded attempt to `Mu(WrongEnsemble)`.

The deterministic grounding assembler also requires the intended member set,
fold groundings, selected surfaces and orthogonality query to name the same
cohort. Each surface authority digest must equal the corresponding fold
grounding digest. Evidence computed for another cohort or substituted after the
fold is refused before plan admission.

## Persona lenses

Personas are reproducible epistemic stances, not simulated personalities:

- historian: chronology, primary records, provenance and supersession;
- idea stormer: bounded divergence before evaluation, preserved outliers;
- theorist: warrant, assumptions and transfer boundaries;
- researcher: primary-source discovery and source-scope checking;
- rigor reviewer: falsification, counterexamples and evidential sufficiency;
- convergence facilitator: tension classification and tradeoff recording without
  becoming a domain advocate.

Each invocation eventually binds an authored role reference and digest, surface
depth, Rune machine/state, evidence scope, capability scope and execution budget.
